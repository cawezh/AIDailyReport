# AI 周报 — 10.26 - 11.01


## 📈 今日技术趋势

本周最核心的信号是 Agent 基础设施正在从「聊天界面」向「可执行、可协作、可治理的运行平台」快速成型：OpenBot、LibreChat、OpenMausBot 分别从本地多代理工作区、自托管多模型门户、VM 沙箱三个角度补齐代理运行环境。第二个强信号是 MCP/SKILL.md 正在成为 AI 工具与专业软件（尤其游戏引擎）之间的标准集成协议，godot-ai、awesome-gamedev-agent-skills、godot-rapier-physics 形成集群。第三，RAG 与安全开始「左移」进模型结构：DecisionRAG 用决策模型替代检索器，HoS 在注意力头层面做提示注入防御。与上周相比，泛 AI 热度未减但明显向 Agent 工程化、沙箱化、协议标准化收敛，同时 Godot+Rust 生态集中爆发，值得下周持续跟踪。


**热点方向：** `Agent 运行环境沙箱化与本地优先：OpenMausBot 给代理内置可丢弃 VM，OpenBot 提供本地多代理工作区与任务队列，Beam.win 解决代理跨设备投射，共同指向「代理需要一台自己的电脑」这一基础设施共识，下一步应关注沙箱隔离、文件权限与代理间通信的标准化方案。` `MCP/SKILL.md 成为 AI 与专业软件集成的通用协议层：godot-ai 提供生产级 MCP 服务器让 Claude 直接操作 Godot 引擎，awesome-gamedev-agent-skills 用 SKILL.md 封装 74 个游戏开发技能，LibreChat 原生集成 MCP/Skills，说明协议层竞争已从聊天插件转向结构化工具调用，建议关注 MCP 在非游戏领域（设计、CAD、运维）的复制速度。` `RAG 从向量检索转向代理式主动检索与结构级安全：DecisionRAG 用决策模型在文档间主动导航替代固定嵌入检索，HoS 在注意力头层面学习门控分离指令与数据流，两者共同表明「检索质量」和「注入防御」正从提示词工程下沉到模型结构与决策过程，做 Agent/RAG 的团队应评估主动检索与结构级防御的落地成本。` `Godot + Rust 生态集群式爆发，开源引擎成为 AI 辅助游戏开发首选试验场：本周同时出现 gdext（官方 Rust 绑定）、godot-rapier-physics（Rust 物理引擎，强调确定性与状态序列化）、godot-ai（MCP 集成）、Nakama（开源游戏后端），形成「脚本快速迭代 + Rust 加速热点 + MCP 代理操作 + 自托管后端」的完整独立开发者栈，建议关注确定性物理与网络同步在开源引擎上的成熟度。` `多智能体从任务自动化走向角色化协作场景：OpenMAIC 用多代理扮演教师/助教/同学生成互动课堂，TradingAgents 用多代理分工做基本面、情绪、决策与风控，Velozity 提出多人共享 AI 办公室，标志多代理设计重心从「工具调用」转向「角色分工与制衡」，下一步应关注多代理协作的评估方法与成本控制，而非单纯堆代理数量。`
